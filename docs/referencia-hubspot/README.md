# Referencias visuales de HubSpot

Regla B punto 6 del proceso (22-nov-2026): aquí viven las capturas de
referencia del HubSpot real del usuario. **Son la fuente de verdad** para
comparar cada pantalla de Omni; toda tarea de UI adjunta su captura
antes/después junto a la referencia correspondiente.

## Convención

- Una carpeta por pantalla, mismo nombre que en `PANTALLAS.md`
  (`contactos-lista/`, `contactos-ficha/`, `empresas-ficha/`, …).
- Dentro, dos archivos: `1440.png` y `1280.png`, capturados con el navegador
  a 1440×900 y 1280×800 (mismos tamaños que los proyectos de Playwright).
- Tema claro, datos reales del HubSpot del usuario.
